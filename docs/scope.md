# Что поддерживает система: элементы и схемы с общими названиями

Дата: 2026-11-01. Статус: черновик на проверку автором. Цель документа - граница класса для генератора v2, разметки и отказов модели: что входит в запросы train и test, а на что правильный ответ - отказ.
Главный критерий - результат работает в MC12: схема считается в пакетном режиме и .CIR открывается пользователем. Столбцы ниже - по текущему коду (`canon.py`, `bench.py`, `spice2cir.py`).

## Концепция: два режима (решение автора 01.11.2026)

В графическом окне программы (поздние версии) пользователь выбирает режим:

| Режим | Запрос | Что делает модель | Кто считает номиналы | Статус |
|---|---|---|---|---|
| Произвольный (ядро работы) | описание конкретной схемы | перевод в нетлист | никто: номиналы заданы | реализуется, основная оценка и таблица моделей |
| Дизайнер | спецификация фильтра | извлечение параметров для дизайнера MC12 | MC12 | дополнение, отдельная метрика; подстановка через `Active.flt` проверена (mc12_pipeline.md) |

Модель фильтры не рассчитывает. Запрос на расчёт в произвольном режиме - отказ с предложением перейти в режим дизайнера. Внутреннее устройство MC12 разрешено исследовать: программа бесплатная (сообщение автора). Папка `DATA` остаётся только для чтения.

## Элементы

| Элемент | Запись | Канон и оценка | .CIR для MC12 | Статус |
|---|---|---|---|---|
| Резистор | `R1 a b 10k` | да | да | поддерживается |
| Конденсатор | `C1 a b 100n` | да | да | поддерживается |
| Катушка | `L1 a b 10m` | да | да | поддерживается |
| Источник напряжения, один, `V1 IN 0 DC x` | | да | да | поддерживается; в запросе - сигнал или постоянное напряжение, `AC 1` добавляет код |
| ОУ, 3 вывода | `X1 плюс минус выход OPAMP_IDEAL` | да (обвязка: E-источник, A = 1e6) | да (Opamp уровня 1, A = 1e6, выводы питания на земле) | поддерживается, только малосигнальный режим |
| Источник тока | `I1 a b ...` | да | **нет**, spice2cir отказывает | только разбор; в генератор не входит (В9) |
| Заземление | узел `0` | да | символ земли | поддерживается, общая земля одна |

Номиналы: суффиксы p, n, u, m, k, MEG, G. Диапазон обучения генератора v1: R 100 Ом - 1 МОм (`gen_range` до 10 МОм), C 100 пФ - 10 мкФ, L 1 мкГн - 100 мГн, характерная частота 10 Гц - 1 МГц, Q 0,5-10. Значения вне диапазона разбираются и считаются, но качество на них отдельно не проверялось.

## Не поддерживается (правильный ответ - отказ с причиной)

| Что | Причина | Может ли MC12 |
|---|---|---|
| Диоды, транзисторы, MOSFET | нелинейные, вне класса; модели и рабочая точка | да, примеры DATA; `cir2spice` их читает, в конвейере оценки нет |
| Цифровые элементы | вне класса | да; `cir2spice` отклоняет |
| Несколько входов: сумматор, вычитатель, дифференциальный усилитель | канон допускает один источник `V1 IN 0` (В1) | да; потребует изменить канон и обвязку |
| Дифференциальный выход (мост) | якорь `OUT` - узел относительно земли | да, но нужна другая метрика |
| Управляемые источники, связанные катушки, трансформатор, линия | нет в каноне | да или не проверялось; вне класса |
| Источники SIN, PULSE; анализ во времени | программа считает только AC; источник функции в канон не входит | да; `cir2spice` читает, конвейер нет |
| Реальные ОУ (TL071 и т.п.), питание, насыщение | малосигнальный идеальный ОУ | да, библиотечные модели (см. mc12_pipeline.md) |

Упоминание питания у ОУ (±12 В, блокировочные конденсаторы) - не отказ: опускается, ОУ идеальный (разметка C01: H0008, H0050). Это соглашение ещё надо подтвердить автором.

## Схемы с общими названиями

Названия, по которым схема собирается без описания соединений: достаточно названия и номиналов по ролям (задача A′). Источник истины - `describe_ru.ROLES`, `data/roles_ru.json`, всего 17, плюс каскады из них.

| Группа | Название | Роли номиналов |
|---|---|---|
| Пассивные | делитель напряжения | R1, R2 |
| | RC ФНЧ / интегрирующая цепь | R, C |
| | RC ФВЧ / дифференцирующая цепь | C, R |
| | RL ФНЧ | L, R |
| | RL ФВЧ | R, L |
| | последовательный RLC-контур, выход на резисторе | L, C, R |
| | параллельный LC-контур с последовательным резистором | R, L, C |
| | двухзвенная RC-цепочка | R1, C1, R2, C2 |
| На одном ОУ | инвертирующий усилитель | R1, R2 |
| | неинвертирующий усилитель | R1, R2 |
| | повторитель | нет |
| | инвертирующий активный ФНЧ | R1, R2, C |
| | инвертирующий активный ФВЧ | R1, C, R2 |
| | интегратор с резистором в ОС | R1, Rf, C |
| | ФНЧ Саллена-Ки | R1, R2, C1, C2, Ra, Rb |
| | ФВЧ Саллена-Ки | C1, C2, R1, R2, Ra, Rb |
| | полосовой MFB (фильтр Рауха) | R1, R2, Ca, Cb, R3 |
| Составные | каскад 2-3 звеньев на ОУ | по звеньям |

Без номиналов схема не собирается: запрос «собери ФНЧ на 1 кГц» - это задача B, расчёт номиналов, вне первой версии.

### Кандидаты на добавление в v2 (встретились в C01 или напрашиваются; решение за автором)

| Название | Чего не хватает | Замечание |
|---|---|---|
| Т-образный и П-образный аттенюаторы | определить роли | только R, просто |
| Интегратор без резистора в ОС | допуск: усиление упирается в A ОУ (H0043) | часто встречается под этим именем |
| Дифференциатор без резистора на входе | проверить развёртку и измерения | |
| Двойной Т-мост (режекторный) | формулы, роли | измерение BS уже есть |
| Произвольные RC/RLC-цепочки и типовые схемы с добавками | нет названия: это задача A, новый механизм композиции | основное расширение v2 |

## Фокус: фильтры всех видов (решение автора 01.11.2026)

Виды и схемы сверяются с дизайнером фильтров MC12, предложения - generator_spec.md, «Предложения для v2 по материалам MC12». Задержка как тип фильтра - Bessel на обычных звеньях (RM12, с. 996), без новых элементов.

Целевой класс сужается до линейных фильтров. Усилители и повторитель остаются как названные схемы и звенья каскадов. Сложные и редкие элементы не рассматриваются, логические схемы - тоже. Новых элементов для таблицы ниже не нужно: всё строится из R, L, C и ОУ.

| Вид | Уже есть | Добавить в v2 (предложение) |
|---|---|---|
| ФНЧ | RC, RL, активный, Саллен-Ки, RC-цепочка | RLC с выходом на C, MFB ФНЧ |
| ФВЧ | RC, RL, активный, Саллен-Ки | RLC с выходом на L, MFB ФВЧ |
| Полосовые | RLC, параллельный LC, MFB, каскад ФВЧ+ФНЧ | - |
| Режекторные | нет | двойной Т-мост; RLC с выходом на последовательном LC |
| Высокого порядка | каскады 2-3 звеньев | LC-лестница |
| Универсальный биквад | нет | на 3 ОУ: кандидат второй очереди, схема сложнее для описания словами |
| Фазовые (всепропускающие) | нет | 1-го порядка на ОУ; нужна метрика фазы |

Баттерворт и Чебышёв - те же схемы с другими номиналами: новых схем не требуют. Запрос «Баттерворт на 1 кГц» - расчёт номиналов, задача B. SC-фильтры - «extra».

### Задержка

Подтверждено руководством:
- Аналоговый макрос Delay (`Documents/delay.pdf`): два зависимых источника для развязки и идеальная линия 50 Ом с задержкой; даёт задержку во временном анализе и сдвиг фазы в AC.
- Цифровая линия DLYLINE (RM12, с. 813) эквивалента в AC не имеет и требует моделей ввода-вывода при подключении к аналоговой части (`delay.pdf`).

Не проверено в конвейере. Логика и DLYLINE нам не подходят; если задержка нужна, то только макрос Delay. Он потребует правок в `canon`, `bench`, `mna`, `spice2cir`, метрики по фазе и анализа Transient для наглядности (сейчас только AC). Решение: отложить до появления конкретной задачи.

## Как граница класса действует на ответы

| Запрос | Ответ модели |
|---|---|
| Всё в классе, описано однозначно, даже если схема странная | нетлист дословно; замечания - проверка программы |
| Вне таблиц выше | отказ с причиной |
| Неоднозначно или противоречиво | отказ с вопросом, что уточнить |
