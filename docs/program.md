# Программа: запрос → нетлист → MC12, сменные переводчики («батарейки»)

Дата: 2026-10-25. Код: `src/mcnl/app.py`, `src/mcnl/translators/`, `src/mcnl/evaluate.py`.

## Конвейер (`app.py`)

```
запрос на русском
  → переводчик (батарейка: baseline / обученная модель)      → строки элементов или JSON-IR
  → разбор и канон (score.parse_output, canon)                → S0
  → характерная частота: узловой расчёт mna.py на 1 Гц - 100 МГц (эталона у пользователя нет)
  → расчёт в MC12 через обвязку bench (AC, ±3 декады)          → S1, измерения measure.py
  → схема .CIR (spice2cir) → по флагу --open открыть в MC12
```

```
python src/mcnl/app.py "RC ФНЧ: R 1к, C 100н; сигнал на вх" --open
python src/mcnl/app.py --netlist схема.txt --open        (свой нетлист, без переводчика)
python src/mcnl/app.py "…" --model путь/model.py:Model    (другая батарейка)
```
Отчёт - JSON: ответ переводчика, ошибки разбора, канонический нетлист, f_хар, результат MC12, измерения (тип АЧХ, k, fc, f0, Q, f_u), путь к .CIR. Рабочая папка (`--out`, по умолчанию `out/app`) должна быть обычной: MC12 не видит перенаправленные папки приложения Claude.

Подключение: `translators.load("baseline")`, `load("mcnl.translators.baseline:RuleBaseline")` или `load("путь/model.py:Model")`; новое имя можно добавить в `translators.REGISTRY`. Программа и оценка от переводчика не зависят: замена батарейки - один параметр `--model`.

## Оценка (`evaluate.py`)

```
python src/mcnl/evaluate.py --model baseline --split test
```
Пишет `out/eval/<модель>_<выборка>/predictions.jsonl` (формат eval_spec, раздел 7), `scores.jsonl`, `summary.json`: доли S0-S4 и функциональной точности с 95% интервалом Уилсона; разбивка по уровню сложности, топологии, задаче (A / A′) и семейству формулировок. Все ответы - одним пакетом MC12; весь test (500) - около 35 с.

## Baseline на правилах (`translators/baseline.py`)

- Задача A - обратный разбор описанных элементов (тот же, что проверяет однозначность запросов генератора).
- Задача A′ - топология по названию из `data/roles_ru.json`, номиналы по ролям, сборка по `formulas.py`; каскады - по звеньям. Минимальная общая терпимость: регистр, разделители «—», «=», «:».
- **На синтетических выборках v1 - 100% (S0-S4, все выборки) по построению**: правила обращают шаблоны генератора. Это проверка конвейера, а не оценка понимания языка. На запросах, написанных иначе, baseline хрупок (из шести пробных «человеческих» формулировок разобрал две: «rc фнч, r=1 кОм, c=100 нФ» и шаблонную). Содержательная планка для моделей - его результат на человеческом тесте.
