# Режим 2: подбор номиналов по характеристикам фильтра (черновик)

Дата: 2026-11-11. Статус: **черновик** - идею принял автор (11.11.2026, после консультации с руководителем), значения по умолчанию и правила подбора - предложение, вопросы к автору в разделе 8. Основа: docs/stage2_plan.md («Консультация с научным руководителем»), docs/designer_mode.md (нынешний путь через дизайнер MC12), docs/eval_spec.md (задача B).

## 1. Идея

Пользователь пишет, какой фильтр нужен: характеристики и, если хочет, схему и часть номиналов. Модель переводит запрос в нетлист, где неизвестные номиналы помечены `?`, и строку целей `.SPEC`. Номиналы считает код: формулы или численный подбор, округление до стандартного ряда, проверка в MC12. Модель номиналы не считает - арифметику она делает ненадёжно, а проверить её нечем.

Роль модели та же, что в режиме 1: понять, какая схема имеется в виду, что в ней задано и что требуется. Запрос без номиналов в режиме 1 сейчас даёт `REFUSE needs_design`; в v3 такие запросы становятся задачей режима 2.

## 2. Что задаёт пользователь

| Параметр | Обязателен | По умолчанию (предложение) |
|---|---|---|
| Тип: ФНЧ, ФВЧ, полосовой (ПФ), режекторный (РФ) | да, либо следует из названной схемы | - |
| Частота: fc (ФНЧ, ФВЧ) или f0 (ПФ, РФ) | да | без частоты - `REFUSE ambiguous: не задана частота` |
| Добротность Q или полоса Δf (ПФ, РФ) | см. вопрос 2 | - |
| Порядок | нет | 2 (см. вопрос 1) |
| Аппроксимация | нет | Баттерворт; Чебышёв - неравномерность 1 дБ, если не задана |
| Усиление в полосе K | нет | 1 (0 дБ); у инвертирующих схем -1 |
| Схема | нет | по таблице раздела 3 |
| Часть номиналов («конденсаторы 10 нФ», «R1 = 10 кОм») | нет | подбираются |
| Ряд номиналов | нет | R - E24, C и L - E12; «точные значения» - без округления |
| Источник | нет | как в режиме 1 |

## 3. Схемы по умолчанию

| Тип | Порядок 1 или «пассивный», «RC», «RLC» | Порядок 2, активный (по умолчанию) | Порядок ≥ 3, Чебышёв ≥ 3 |
|---|---|---|---|
| ФНЧ | RC (`rc_lp`) | Саллен-Ки, единичное усиление (`sallen_key_lp`); при K ≠ 1 - МОС ФНЧ (`mfb_lp`) | дизайнер MC12, стиль Sallen-Key |
| ФВЧ | RC (`rc_hp`) | Саллен-Ки, единичное усиление (`sallen_key_hp`); при K ≠ 1 - МОС ФВЧ (`mfb_hp`) | дизайнер MC12, стиль Sallen-Key |
| ПФ | последовательный RLC, выход на R (`rlc_series_bp`) | МОС (`mfb_bp`) | дизайнер MC12, стиль MFB |
| РФ | двойной Т-мост (`twin_t`) | двойной Т-мост с повторителем или Тоу-Томас (`tow_thomas`) - см. вопрос 7 | дизайнер MC12, стиль Tow-Thomas |

Названная или описанная пользователем схема из класса всегда важнее таблицы. Бессель 2-го порядка - те же схемы с другими Q и масштабом частоты; Бессель выше 2-го порядка дизайнер MC12 не строит (только тип Delay, docs/designer_mode.md).

## 4. Правила подбора номиналов (предложение)

Неизвестных столько, сколько целей; остальные номиналы фиксируются соглашениями:

| Схема | Соглашение | Расчёт |
|---|---|---|
| RC ФНЧ, ФВЧ | C из ряда так, чтобы R был ближе к 10 кОм (в пределах 1-100 кОм) | R = 1 / (2π fc C) |
| RL ФНЧ, ФВЧ | L из ряда так, чтобы R был в пределах 10 Ом - 10 кОм | R = 2π fc L |
| Саллен-Ки ФНЧ, K = 1 | R1 = R2 = R, C на землю из ряда | C в ОС = 4Q² · C на землю; R = 1 / (2π f0 √(C1 C2)) |
| Саллен-Ки ФВЧ, K = 1 | C1 = C2 = C из ряда | R на землю = 4Q² · R в ОС; f0 = 1 / (2π C √(R1 R2)) |
| МОС ПФ | C1 = C2 = C из ряда | R3 = Q / (π f0 C); R1 = R3 / (2|K|); R2 = R3 / (4Q² - 2|K|), нужно 2Q² > |K| |
| Последовательный RLC ПФ | L из ряда | C = 1 / ((2π f0)² L); R = √(L/C) / Q |
| Двойной Т-мост | R, R, R/2 и C, C, 2C; C из ряда | R = 1 / (2π f0 C) |
| Описанная пользователем схема без формулы | - | численный подбор по узловому расчёту (`mna.py`), до 3 неизвестных |

- Диапазоны: R - 100 Ом...1 МОм (предпочтительно 1...100 кОм), C - 100 пФ...10 мкФ, L - 1 мкГн...100 мГн. Если в диапазон не уложиться, программа говорит, что мешает («для 1 Гц на RC нужен C больше 10 мкФ»).
- Округление: к ряду; затем перебор соседних значений ряда (2-3 варианта на номинал) с наименьшим отклонением fc, f0, Q. Отклонение после округления показывается всегда.
- Проверка: готовая схема считается в MC12, как в режиме 1; в отчёте - заданное и полученное.

Формулы Саллен-Ки ФНЧ и МОС ПФ проверены прогоном в MC12, остальные - нет (11.11.2026, docs/mc12_pipeline.md, «Реальные ОУ»): Саллен-Ки ФНЧ 1 кГц, Q 0,707 - fc 1000,4 Гц, Q 0,707; МОС ПФ 10 кГц, Q 5, K -1 - f0 9995,6 Гц, Q 5,00, 0 дБ.

## 5. Ответ модели

Схема с неизвестными:
```
V1 IN 0 DC 0
R1 IN N1 ?
R2 N1 N2 ?
C1 N1 OUT 10n
C2 N2 0 10n
X1 N2 OUT OUT OPAMP_IDEAL
.SPEC type=LP fc=1k Q=0.707
```
Только характеристики, схему выбирает программа (раздел 3):
```
.SPEC type=LP fc=1k order=4 response=Butterworth
```
Поля `.SPEC`: `type` (LP, HP, BP, BS), `fc`, `f0`, `Q`, `bw`, `K`, `order`, `response` (Butterworth, Chebyshev, Bessel), `ripple`, `series`. Не названное в запросе не пишется - значение по умолчанию подставляет код. `?` стоит только на месте номинала. Отказы - как в режиме 1. Номиналы - в записи канона (`10k`, `4.7n`), частоты в `.SPEC` - так же.

## 6. Что делает код

1. Разбор `?` и `.SPEC` (`canon` с расширением).
2. Узнаёт топологию: изоморфизм со схемами `formulas.TOPOLOGIES` и `filters_v2`. Есть формула - расчёт по разделу 4, нет - численный подбор.
3. Округление, MC12, отчёт; .CIR - как в режиме 1. Порядок ≥ 3 - путь дизайнера MC12 (docs/designer_mode.md).

## 7. Данные v3 и оценка

- Примеры: из схем генератора v3 скрываются 1-3 номинала, цели берутся из измерений эталона; новые шаблоны запросов («нужен ФНЧ на 2 кГц, конденсаторы по 10 нФ»). Плюс запросы только с характеристиками (ответ - одна строка `.SPEC`). Доля - около 15-20% train v3.
- Оценка: схема - S2 (изоморфизм, `?` на тех же местах, заданные номиналы - S3); `.SPEC` - точное совпадение полей; поведение - подобранная кодом схема в MC12 укладывается в допуск по fc, f0, Q (после округления к ряду - в пределах шага ряда, точно - уточнить).

## 8. Вопросы к автору

1. Запрос «ФНЧ на 1 кГц» без уточнений: активный 2-го порядка (Саллен-Ки, Баттерворт) или RC 1-го порядка?
2. ПФ и РФ без добротности и полосы: отказ с вопросом или Q по умолчанию (какое)?
3. Ряды: R - E24, C и L - E12, или R - E96?
4. Режим выбирается в окне явно (переключатель) или определяется по запросу?
5. Порядок ≥ 3: дизайнер MC12, как сейчас (схема дизайнера, запуск окна MC12), или свой расчёт каскадом звеньев 2-го порядка (наши схемы, без окна MC12, быстрее)?
6. Всепропускающие фильтры (фазовращатели) - в класс v3?
7. Активный режекторный по умолчанию: двойной Т-мост с повторителем или Тоу-Томас?
