# Режим 2: подбор номиналов по характеристикам фильтра

Дата: 2026-11-11. Статус: идея и значения по умолчанию согласованы с автором 11.11.2026 (раздел 8); формулы, кроме отмеченных, в MC12 ещё не проверены. Основа: docs/stage2_plan.md («Консультация с научным руководителем», «Решения автора 11.11.2026»), docs/designer_mode.md (путь через дизайнер MC12), docs/eval_spec.md (задача B).

## 1. Идея

Пользователь пишет, какой фильтр нужен: характеристики и, если хочет, схему и часть номиналов. Модель переводит запрос в нетлист, где неизвестные номиналы помечены `?`, и строку целей `.SPEC`. Номиналы считает код: формулы или численный подбор, округление до стандартного ряда, проверка в MC12. Модель номиналы не считает - арифметику она делает ненадёжно, а проверить её нечем.

Роль модели та же, что в режиме 1: понять, какая схема имеется в виду, что в ней задано и что требуется. Режим выбирается переключателем в окне (раздел 5).

## 2. Что задаёт пользователь

| Параметр | Обязателен | По умолчанию |
|---|---|---|
| Тип: ФНЧ, ФВЧ, полосовой (ПФ), режекторный (РФ) | да, либо следует из названной схемы | - |
| Частота: fc (ФНЧ, ФВЧ) или f0 (ПФ, РФ) | да | без частоты - `REFUSE ambiguous: не задана частота` |
| Исполнение | нет | **пассивное**; ОУ - только если запрос говорит «активный», «на ОУ» или называет активную схему |
| Порядок | нет | ФНЧ, ФВЧ - 1; если названа аппроксимация (Баттерворт, Чебышёв) - 2; ПФ, РФ - 2 |
| Аппроксимация | нет | Баттерворт; Чебышёв - неравномерность 1 дБ, если не задана |
| Добротность Q или полоса Δf | нет | ФНЧ, ФВЧ - по аппроксимации (Баттерворт 2-го порядка - 0,707); ПФ, РФ - **Q = 1** (полоса равна f0) |
| Усиление в полосе K | нет | 1 (0 дБ); у инвертирующих схем -1 |
| Схема | нет | по таблице раздела 3 |
| Часть номиналов («конденсаторы 10 нФ», «R1 = 10 кОм») | нет | подбираются |
| Ряд номиналов | нет | R - E24, C и L - E12 (стандартные; высокая точность при остальных округлённых номиналах не нужна) |
| Источник | нет | как в режиме 1 |

Почему у ПФ и РФ Q = 1, а не 0,707: при Q = 0,707 полоса шире центральной частоты в 1,4 раза (у 1 кГц - примерно 520...1930 Гц), а полосовой МОС с K = -1 вырождается (R2 = R3 / (4Q² - 2|K|) уходит в бесконечность). Q = 1 - круглое и понятное значение: полоса равна f0.

## 3. Схемы по умолчанию

| Тип | Пассивный (по умолчанию) | Активный («активный», «на ОУ») |
|---|---|---|
| ФНЧ, 1-й порядок | RC (`rc_lp`) | инвертирующий активный ФНЧ (`active_lp_inv`) |
| ФНЧ, 2-й порядок | последовательный RLC, выход на C (`rlc_series_lp`) | Саллен-Ки, K = 1 (`sallen_key_lp`); при K ≠ 1 - МОС ФНЧ (`mfb_lp`) |
| ФВЧ, 1-й порядок | RC (`rc_hp`) | инвертирующий активный ФВЧ (`active_hp_inv`) |
| ФВЧ, 2-й порядок | последовательный RLC, выход на L (`rlc_series_hp`) | Саллен-Ки, K = 1 (`sallen_key_hp`); при K ≠ 1 - МОС ФВЧ (`mfb_hp`) |
| ПФ | последовательный RLC, выход на R (`rlc_series_bp`) | МОС (`mfb_bp`) |
| РФ | последовательный RLC, выход на LC (`rlc_series_bs`); «без катушек» - двойной Т-мост (`twin_t`, Q = 0,25 у него постоянно) | двойной Т-мост с повторителями и обратной связью через делитель (Q задаётся делителем) |
| ФНЧ, ФВЧ, порядок ≥ 3 | LC-лестница с равными нагрузками (`lc_ladder3`, `lc_ladder5`); Чебышёв - только нечётный порядок | каскад звеньев Саллен-Ки 2-го порядка и, при нечётном порядке, RC-звена с повторителем |
| ПФ, РФ выше 2-го порядка; инверсный Чебышёв | дизайнер MC12 (docs/designer_mode.md) | дизайнер MC12 |

Названная или описанная пользователем схема из класса всегда важнее таблицы. Бессель - те же схемы с другими Q и масштабом частоты; Бессель выше 2-го порядка дизайнер MC12 не строит.

Активный РФ на двойном Т-мосте по устройству близок к схеме `twin_t_notch` из проверочной выборки `mc12_real`: если он войдёт в train v3, эту схему в `mc12_real` нужно показывать отдельно.

## 4. Правила подбора номиналов

Неизвестных столько, сколько целей; остальные номиналы фиксируются соглашениями:

| Схема | Соглашение | Расчёт |
|---|---|---|
| RC ФНЧ, ФВЧ | C из ряда так, чтобы R был ближе к 10 кОм (в пределах 1-100 кОм) | R = 1 / (2π fc C) |
| RL ФНЧ, ФВЧ | L из ряда так, чтобы R был в пределах 10 Ом - 10 кОм | R = 2π fc L |
| Инвертирующие активные 1-го порядка | R1 = 10 кОм | Rf = |K| · R1; C из fc = 1 / (2π Rf C) (ФНЧ) или 1 / (2π R1 C) (ФВЧ) |
| Последовательный RLC (ФНЧ, ФВЧ, ПФ, РФ) | L из ряда | C = 1 / ((2π f0)² L); R = √(L/C) / Q |
| Саллен-Ки ФНЧ, K = 1 | R1 = R2 = R, C на землю из ряда | C в ОС = 4Q² · C на землю; R = 1 / (2π f0 √(C1 C2)) |
| Саллен-Ки ФВЧ, K = 1 | C1 = C2 = C из ряда | R на землю = 4Q² · R в ОС; f0 = 1 / (2π C √(R1 R2)) |
| МОС ПФ | C1 = C2 = C из ряда | R3 = Q / (π f0 C); R1 = R3 / (2|K|); R2 = R3 / (4Q² - 2|K|), нужно 2Q² > |K| |
| Двойной Т-мост | R, R, R/2 и C, C, 2C; C из ряда | R = 1 / (2π f0 C) |
| Каскад Баттерворта n-го порядка | звенья с f0 = fc | Q звена k = 1 / (2 sin((2k - 1)π / (2n))), k = 1...⌊n/2⌋ |
| Каскад Чебышёва | - | f0 и Q звеньев - по полюсам Чебышёва (формулы через sh, ch) |
| LC-лестница Баттерворта, Rs = Rl = R | R = 1 кОм или задан | g_k = 2 sin((2k - 1)π / (2n)); L = g R / (2π fc), C = g / (2π fc R) |
| Описанная пользователем схема без формулы | - | численный подбор по узловому расчёту (`mna.py`), до 3 неизвестных |

- Диапазоны: R - 100 Ом...1 МОм (предпочтительно 1...100 кОм), C - 100 пФ...10 мкФ, L - 1 мкГн...100 мГн. Если в диапазон не уложиться, программа говорит, что мешает («для 1 Гц на RC нужен C больше 10 мкФ»).
- Округление: к ряду; затем перебор соседних значений ряда (2-3 варианта на номинал) с наименьшим отклонением fc, f0, Q. Отклонение после округления показывается всегда.
- Проверка: готовая схема считается в MC12, как в режиме 1; в отчёте - заданное и полученное.

Проверено прогоном в MC12 (11.11.2026, docs/mc12_pipeline.md, «Реальные ОУ»): Саллен-Ки ФНЧ 1 кГц, Q 0,707 - fc 1000,4 Гц, Q 0,707; МОС ПФ 10 кГц, Q 5, K -1 - f0 9995,6 Гц, Q 5,00, 0 дБ. Остальные формулы - не проверены; Q активного двойного Т-моста через делитель - вывести и проверить.

## 5. Режимы и ответ модели

Режим выбирается переключателем в окне (решение автора 11.11.2026): так проще и для пользователя, и для модели. У каждого режима своя инструкция модели:
- **Режим 1** - как в v2: все номиналы заданы, ответ - нетлист. Запрос без номиналов - `REFUSE needs_design` с подсказкой перейти в режим 2. Поведение режима 1 не меняется, поэтому модели на v2 и v3 сравнимы на его выборках.
- **Режим 2** - ответ - нетлист с `?` и строкой `.SPEC`, либо одна строка `.SPEC`, если схема не названа и не описана (её выбирает код по разделу 3).

Схема с неизвестными:
```
V1 IN 0 DC 0
R1 IN N1 ?
R2 N1 N2 ?
C1 N1 OUT 10n
C2 N2 0 10n
X1 N2 OUT OUT OPAMP_IDEAL
.SPEC type=LP fc=1k Q=0.707
```
Только характеристики:
```
.SPEC type=LP fc=1k order=4 response=Butterworth
```
Поля `.SPEC`: `type` (LP, HP, BP, BS), `fc`, `f0`, `Q`, `bw`, `K`, `order`, `response` (Butterworth, Chebyshev, Bessel), `ripple`, `active` (yes - если запрос просит активный), `series`. Не названное в запросе не пишется - значение по умолчанию подставляет код. `?` стоит только на месте номинала. Отказы - как в режиме 1. Номиналы и частоты - в записи канона (`10k`, `4.7n`).

## 6. Что делает код

1. Разбор `?` и `.SPEC` (`canon` с расширением).
2. Узнаёт топологию: изоморфизм со схемами `formulas.TOPOLOGIES` и `filters_v2`. Есть формула - расчёт по разделу 4, нет - численный подбор.
3. Округление, MC12, отчёт; .CIR - как в режиме 1.
4. Дизайнер MC12 - только для ПФ и РФ выше 2-го порядка и инверсного Чебышёва. Остальное считает код: управление окном дизайнера проверено только на 32-битном MC12 12.2.0.5, а у заочников на домашних ПК версии и настройки разные; дизайнер открывает окно MC12 на каждую схему, выбирает свою схему и по-своему определяет частоту (docs/designer_mode.md). Собственный расчёт строит наши схемы, работает в пакетном режиме и проверяется так же, как режим 1.

## 7. Данные v3 и оценка

- Примеры режима 2 - со своей инструкцией: из схем генератора v3 скрываются 1-3 номинала, цели берутся из измерений эталона; новые шаблоны запросов («нужен ФНЧ на 2 кГц, конденсаторы по 10 нФ», «активный полосовой на 5 кГц»). Плюс запросы только с характеристиками (ответ - одна строка `.SPEC`). Доля - около 15-20% train v3.
- Оценка: схема - S2 (изоморфизм, `?` на тех же местах, заданные номиналы - S3); `.SPEC` - точное совпадение полей; поведение - подобранная кодом схема в MC12 укладывается в допуск по fc, f0, Q (после округления к ряду - в пределах шага ряда; точный допуск - при реализации).

## 8. Решения автора (11.11.2026)

1. По умолчанию - пассивный фильтр; ОУ - если запрос просит «активный» или называет активную схему.
2. Значение Q по умолчанию нужно: ФНЧ, ФВЧ - по аппроксимации, ПФ и РФ - 1 (обоснование - раздел 2).
3. Ряды - стандартные: R - E24, C и L - E12.
4. Режим - переключатель в окне.
5. Порядок ≥ 3 - на усмотрение Claude: собственный расчёт для ФНЧ и ФВЧ (каскад, LC-лестница), дизайнер MC12 - только для ПФ, РФ выше 2-го порядка и инверсного Чебышёва (раздел 6).
6. Всепропускающие фильтры (фазовращатели) - на усмотрение Claude: как названные схемы в v3 не добавляются. Их АЧХ ровная, а предпросмотр в программе - только АЧХ; польза для учебной программы о фильтрах мала. Описанный соединениями фазовращатель модель переводит как любую схему класса.
7. Активный режекторный по умолчанию - на усмотрение Claude: двойной Т-мост с повторителями и делителем в обратной связи (учебная схема, Q задаётся делителем).
