# CLAUDE.md

Магистерская диссертация: преобразование запроса на естественном языке в SPICE-нетлист
обученной открытой моделью и его выполнение в Micro-Cap 12 (MC12). Побочная цель -
учебный инструмент для университета (вторичен по отношению к диссертации).

## Как работать с автором
- Общение на русском. Оценки честные, без лишней похвалы; стиль ближе к научной работе.
- Утверждения о MC12 подкреплять страницей руководства (`ug12.pdf`, `rm12.pdf`) или
  проверкой; разделять «подтверждено», «восстановлено по примерам», «не проверено».
- Перед крупной работой с неочевидным объёмом спросить; мелкое делать сразу.

## Архитектура
```
текст → (обученная модель) → SPICE-нетлист → (детерминированный код) → .ckt / .CIR → MC12 (пакетный режим) → .ANO/.TNO
```
- Модель генерирует только нетлист; координаты, чертёж и .CIR строит код. Модель
  координат не касается.
- Чертёж: элементы расставляются, соединения задаются метками узлов на выводах; провода
  необязательны (вариант без проводов проверен в MC12).
- Сравнение моделей ведётся по нетлисту: синтаксис → запуск → топология (netlist_compare)
  → номиналы → поведение (симуляция против спецификации запроса).

## Этапы
1. Основа без ИИ (текущий, самый объёмный): выполнение в MC12, стенд оценки, данные,
   конвертеры, замороженная тестовая выборка, baseline на правилах.
2. Обучение и сравнение открытых моделей (Hugging Face, LoRA/QLoRA в Colab), таблица
   точности и ресурсов, выбор.
3. Встраивание лучшей модели в программу, тесты. Интерфейс, интерактив, SC-фильтры -
   «extra».

## Данные и оценка (решения, подробно - docs/eval_spec.md)
- Задача A: перевод описания (схема и номиналы заданы в запросе); A′ - топология названа
  словами. B (синтез по спецификации, в т.ч. через Design → Active Filters MC12) - после A.
- Запросы на русском.
- Модель пишет только элементы схемы (вкл. описанный источник); анализы, .PRINT, библиотеку
  ОУ добавляет код. ОУ - идеальная подсхема `OPAMP_IDEAL`, малосигнальный режим.
- Два формата выхода для сравнения: канонический нетлист и JSON-IR `mcnl.ir/1`.
- Оценка: уровни S0 разбор → S1 запуск → S2 топология → S3 номиналы (основная, exact match)
  → S4 поведение; сравнение через изоморфизм, не по именам элементов.
- Основной корпус - синтетический генератор целевого класса с эталоном, который
  гарантированно запускается. Masala-CHAI не годится как мерило качества
  (docs/audit_masala_chai_batch100.md). Тест - формулировки людей; деление по схемам.

## Окружение автора
- Windows, i5-10300H, GTX 1660 Ti Max-Q (6 ГБ, Turing, без bf16). Обучение - Colab.
- Micro-Cap 12: `C:\MC12\Micro-Cap 12.exe` (64 бит, им запускается пакетный режим) и
  `C:\MC12\mc12.exe` (32 бит); примеры `C:\MC12\DATA`, руководства `C:\MC12\Documents`.
  Python 3.12: `%LOCALAPPDATA%\Programs\Python\Python312\python.exe`.
  Папка примеров `DATA` - только читать, оригиналы не менять.
- Генерируемые файлы складывать в `out/` (в .gitignore), не в tests/ и не в DATA.

## Код
- `src/mcnl/cir2spice.py` - .CIR → SPICE. `netlist_compare.py` - топология и номиналы.
  `mc12run.py` - пакетный запуск .ckt в MC12. `mcout.py` - разбор .ANO/.TNO, частота среза.
  `make_test_cir.py` - тестовый .CIR. `audit_netlists.py` - аудит Masala-CHAI.
- Оценка (eval_spec): `canon.py` - канон и JSON-IR; `iso.py` - изоморфизм; `bench.py` - обвязка
  и OPAMP_IDEAL; `measure.py` - измерения и допуски; `score.py` - уровни S0-S4 и сводка;
  `formulas.py` - топологии L1/L2 и формулы; `mna.py` - узловой расчёт без MC12;
  `pilot.py` - пилот эталонов и допуск в датасет.
- Датасет v2 (docs/generator_v2_spec.md): `filters_v2.py` - новые топологии (отдельно от formulas.TOPOLOGIES, v1 воспроизводится);
  `compose.py` - цепочки и добавки, запросы к ним;
  главная метрика - data/dataset/llm_test_v1 (заморожена).
- Генератор: `sampler.py` - номиналы; `cascade.py` - каскады L3; `describe_ru.py` - русские
  запросы и их обратный разбор (словарь ролей - data/roles_ru.json); `generate.py` - сборка.
- Программа: `app.py` - конвейер «запрос → .CIR → MC12»; `translators/` - сменные переводчики
  (интерфейс: output_format + translate(prompt); подключение load("файл.py:Класс")); `evaluate.py` -
  оценка переводчика на выборке. Подробно - docs/program.md.
- `spice2cir.py` - нетлист → .CIR (шаблоны элементов - data/cir_templates.cir; блок `[Text Area]`
  только в формате `Text=` и после `[Page]`, иначе MC12 не загружает файл).
- Нетлист, совпавший по топологии, ещё не обязательно запускается (порядок `AC 1` и функции
  источника, .PRINT по узлам): проверять настоящим прогоном через mc12run.
- Тесты: `python -m unittest discover -s tests` (должны проходить перед коммитом).
- Только стандартная библиотека Python 3.9+, пока не обосновано иное.
- Файлы для MC12 (.ckt, .cir, .bat) писать в ASCII/cp1251 с CRLF; кириллицу в них не
  вставлять.

## Сверка с MC12
- File → Translate делать на копии .cir в `%USERPROFILE%\Documents\mc12_translate` (MC12 не
  видит перенаправленную папку приложения Claude; DATA не трогать): тип Micro-Cap Spice,
  Transient + AC. Эталоны - в tests/reference, локальный путь в первой строке заменять.
