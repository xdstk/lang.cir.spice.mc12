# lang.cir.spice.mc12

Магистерская диссертация: преобразование запроса на естественном языке (русский) в SPICE-нетлист обученной открытой моделью и его выполнение в Micro-Cap 12 (MC12). Побочная цель - учебная программа для студентов-заочников.

```
текст → (обученная модель) → SPICE-нетлист → (код) → .CIR / .ckt → MC12 (пакетный режим) → АЧХ, измерения
```

Модель пишет только нетлист (или задание на подбор номиналов, режим 2); схему, чертёж и расчёт в MC12 строит детерминированный код. Модели сравниваются по нетлисту: разбор → запуск → топология → номиналы (основная метрика S3, точное совпадение) → поведение в MC12.

Окружение: Python 3.12, проектный код - только стандартная библиотека; модель - отдельное окружение `..\venv-hf` (torch, transformers, peft, bitsandbytes), обучение - Colab. MC12 - `C:\MC12`.

```
python src/mcnl/app.py "RC ФНЧ: R 1к, C 100н; сигнал на вх" --open
run_gui.bat                                                    (окно программы, Qwen3.5-4B)
python src/mcnl/evaluate.py --model baseline --split test --data data/dataset/v2
python src/mcnl/evaluate.py --predictions ответы.jsonl --split test --data data/dataset/v3_2/mode1   (ответы из Colab)
python -m unittest discover -s tests                           (около 13 мин, нужен MC12)
```

Файлы для MC12 - в обычной папке (не в перенаправленных папках приложений). Примеры `tests/data/OPAMP1.cir`, `Sallen-Key_High_Pass_Filter.cir`, `Counter.cir` взяты из поставки Micro-Cap 12 (Spectrum Software).
