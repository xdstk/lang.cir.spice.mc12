# Синтетический датасет v1: запрос на русском → SPICE-нетлист

Собран `src/mcnl/generate.py` (версия генератора `gen-1`) по `docs/generator_spec.md` с решениями автора В1-В10 и семейством `brief`.
Команда: `python src/mcnl/generate.py --out data/dataset/v1 --seed 20261025`.
Числа, SHA-256 файлов и отчёт о допуске - в `manifest.json`.

## Выборки

| Файл | Схем | Записей | Назначение |
|---|---|---|---|
| `train.jsonl` | 1000 | 2000 | обучение; по 2 формулировки на схему (вложенное подмножество «по 1 формулировке» - для сравнения размеров 1000 / 2000) |
| `dev.jsonl` | 150 | 150 | подбор гиперпараметров |
| `test.jsonl` | 500 | 500 | **заморожен** до первого обучения (SHA-256 ниже) |
| `gen_topology.jsonl` | 100 | 100 | топологии, которых нет в остальных выборках: MFB полосовой, RL ФВЧ, каскад ФВЧ+ФНЧ |
| `gen_family.jsonl` | 100 | 100 | семейство шаблонов `path`, которого нет в остальных выборках (только задача A) |
| `gen_range.jsonl` | 100 | 100 | хотя бы один резистор больше 1 МОм (в остальных выборках R ≤ 1 МОм) |

Одна схема (`circuit_id`) встречается только в одной выборке.

## Запись

`id`, `circuit_id`, `split`, `task` (`A` - элементы перечислены, `A1` - топология названа словами), `topology`, `level` (L1-L3), `family` (`list`, `table`, `narrative`, `brief`, `path`; у A1 - `roles` / `roles_brief`), `prompt`, `netlist` (канонический, метка для формата «нетлист»), `ir` (JSON-IR `mcnl.ir/1`, метка для формата «IR»), `params`, `f_char`, `quantities`, `expected` (формула или узловой расчёт), `measured` (MC12), `admission`, `gen`.

Модель пишет только строки элементов (или IR); заголовок, `OPAMP_IDEAL`, `AC 1`, анализы и `.END` добавляет обвязка `bench.py` (docs/eval_spec.md, раздел 4). Оценка - `score.py`, уровни S0-S4.

## Гарантии

- Каждая схема прошла допуск (eval_spec, раздел 9): канон и круговое преобразование нетлист ↔ IR; запуск в MC12 без Error; измерения MC12 совпадают с формулой (L1/L2) или с узловым расчётом `mna.py` (каскады L3) - частоты 0,3%, уровни 0,2% (предел точности вывода MC12), формула против `mna.py` - 0,1% / Q 1%.
- Каждый запрос задачи A прошёл обратный разбор: из текста однозначно восстанавливается метка (изоморфизм по номиналам).
